# 天意 HR 全模块逻辑联检

2026 年 11 月 24 日。此次使用天意集团隔离演示数据，按「页面入口、业务状态、上下游来源、角色权限」逐项核对。从浏览器打开原有菜单的 60 个入口，59 个正常进入，1 个个人入口显示条件有误。个人自助使用有人员绑定的员工账号，系统设置使用配置管理员账号。提交、审批、复核、重试和拒绝路径使用独立测试数据执行。

## 本轮修正

| 发现 | 影响 | 修正 |
|---|---|---|
| 无员工绑定的演示操作员看到“我的假期” | 点个人入口后服务端正确拒绝，导航让用户误以为是页面故障 | 显示条件同时检查自助权限与员工身份。员工自助与 HR 假期管理照常开放 |
| 门店过滤可能把集团正式班表当成门店计划复制 | 复制时范围不符，后端拒绝建草稿 | 服务端返回排班版本的原始集团范围。门店能查看集团正式排班，集团范围复制集团版本。门店可复制本店的正式版 |

## 验证路径

| 模块 | 核对路径及关键状态 |
|---|---|
| 组织、花名册与编制 | 从集团、品牌、门店、部门与岗位筛选人员，穿透花名册。检查永久号与多段雇佣分别用于人员历史与业务发生，查满编、缺编、超编和历史版本 |
| 入转调离 | 核对人事操作、组织范围、实际生效与人员全貌。跨店支援保持原雇佣，正式调店按人事记录生效 |
| 招聘 | 需求、候选人、面试、Offer 到入职登记。候选状态和正式雇佣分开，原件导入人工核对 |
| 合同 | 归属雇佣、工资条款、生效期间和到期提醒。合同映射的已核项目可取入期间算薪 |
| 排班与打卡 | 门店、雇佣、日期过滤，多班与跨午夜，手动画班和复制，借调与补卡。独立发布建立正式版本；历史草稿或旧正式版可追溯 |
| 假期 | 假期设置、余额及本人提交，经审批、实际已休核定进入核勤。区分排班分钟、日历天和法定配置 |
| 日报与月报 | 对照排班、实际打卡、已休与核定。按版本导出，Excel 预检、人工调整与复核保留依据。重发排班后检查关联的月报与工资来源 |
| 薪酬 | 项目发布、方案与公式、按人或按店分配、工资档案及 Excel 导入；按月份、雇佣关系及工资体系取配置。检查已核来源、公式试算、批次预演、独立复核、确认和个人工资单 |
| 付款、申报与成本 | 工资确认、付款指令、付款回执与申报受理分别推进。独立核对内地与香港、发薪主体、币种与成本归属；测试数据回执仅用于流程验证 |
| 绩效 | 计划、评议、评分、独立复核、发布、通知和异议；两种奖金可分别试算，按发布版本选择一套进入工资来源 |
| 培训与考试 | 学习任务、考核或实操、成绩、申诉和岗位资格；公布记录进入人员全貌，奖金用已核版本，旧成绩更正需重新采用 |
| 宿舍与证照 | 入住、换房、退宿的申请和实际交接，按规则提取已核费用；门店与人员证照期限、续期与提醒 |
| 物品、福利及供应商 | 核对申请、审批、领用/退回、库存和人员记录；核定派驻服务量、工作门店归属、供应商对账及结算状态 |
| 统一审批和门户 | 配置表单及审批节点，分别查看待办、我的申请、已办和消息。核对审批、执行、结果通知与人员自助入口的实际身份 |
| 权限与集成 | 核对角色、功能权限、字段和集团/部门/门店权限。员工直达工资方案被拒绝，配置管理员直达工资与成本被拒绝。检查平台接入、人员对照和原始打卡的测试配置、回执状态入口 |

## 证据与验收范围

- 生产前端构建和完整 `npm test` 通过，执行 40 组测试命令。文档基线与数据库对象统计一致。
- 浏览器覆盖原有 60 个菜单入口。核对集团演示操作员、员工、配置管理员三种界面。检查员工本人排班、假期、工资单、学习和绩效，并验证两类非授权账号的直达拒绝。
- 隔离 PostgreSQL 从空库应用 242 项迁移并核验账本哈希，生成 62 人、77 个账号、20 家门店及 52 个扩展场景。测试工厂外部调用为零。
- 排班专项通过 64 项本地集成断言。排班范围修正另外经 PostgreSQL 15 项断言确认，包含换版、保留历史、过滤、多门店查询、导出、集团版投影和原范围复制。前端 134 项验证通过。实际界面复验了门店查看集团版、返回集团范围打开复制草稿，以及演示账号的个人假期入口。
- PostgreSQL 工资设置 39 项、跨模块公式 27 项、真实绩效奖金来源应用 8 项全部通过。涵盖跨店批量复制、逐人方案、Excel、内地和香港来源取数、同源更正净差及数据库独立复算。
- 正式企业应用、电子签、考勤设备、银行和法定机构使用各自的生产凭据与真实回执独立验收。当前资料和本地操作使用演示数据。
