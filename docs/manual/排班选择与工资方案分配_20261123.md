# 排班选择与工资方案分配

2026 年 11 月 23 日。适用于数据结构保持 242 的新版。

## 排班工作台

进入「排班考勤 → 排班工作台」，在班表上方展开「工作门店」勾选一个或多个公司或门店，再展开「排班人员」，按姓名或永久编号查找实际工作关系。人员名单包含在所选门店有可见班段的借入人员。遇到同名或跨店任职，可按原雇主和员工编号区分。

选多家店可对照当前正式班表，选择一家店后可切换排班版本并编辑草稿。日时间轴输入例如 18:30，点击「跳到时间」。周和月视图继续使用相同的门店与人员筛选。排班 Excel 导出按所选人员、门店及视图日期范围导出。编辑、发布与独立复核仍沿用排班版本规则。

人员时间轴和选人思路参考鸿欢《高级排班产品白皮书》中的按人员排班、分页、日周视图和手动画班。多店选择与时间定位采用天意已有的工作门店与实际雇佣模型。

## 工资方案

薪酬设置页顶部可直接切换四个步骤：

1. 「工资项目」定义项目名称、编码和类型。新项目经另一位有权人员复核后可用于方案。
2. 「工资方案与公式」建立方案并选择公司与算薪体系，再在「项目与公式」添加工资项目、配置公式和试算。输入变量、来源待遇和跨模块取数在同一编辑窗口单独维护。「批量复制」可把已发布方案的项目与公式复制成各目标店的草稿，目标店须在生效月份已启用同一体系。不同门店独立复核发布。
3. 「员工方案分配」选生效月份，查看当月已分配及待复核的方案。可在一行点「分配方案」，也可选一家店后勾选多人或点「选择本店全部匹配人员」。同店不同人员可以使用不同方案。选择已发布方案，按需补录新方案要求的工资参数，预检后提交复核。
4. 「员工工资档案」查看已分配方案，直接修改金额、批量填值或从 Excel 导入。选择待复核档案，由另一位有权人员核对并生效。不同方案按各自适用人员进入工资批次。

参考[人力家智能薪酬](https://www.renlijia.com/salary.html)的多套规则与工资档案，以及[易路 People+ 实施文档](https://support.huaweicloud.com/eroad-peoplehcm-saasapp/eroad-peoplehcm_34.html)的按方案组织核算、确认人员及数据校验。天意的分配对象是一段实际雇佣，方案按月份生效。已有确认工资的月份需走更正；新发布的复制方案由员工分配后投入使用。
