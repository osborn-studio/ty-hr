# 工资项目公式与跨模块算薪操作补充

2026-11-18，适用于242版本。与原完整操作手册配套使用；本补充覆盖工资项目、公式、工资表直接编辑和Excel导入的新入口。

## 一、从工资项目进入公式

在“薪酬管理 → 工资项目设置”找到项目，点击该行“设置公式”。选择公司或门店的工资方案，可看到该项目在方案中的现行公式；选择“设置公式”建立新修订。不同门店可以为同一项目使用不同公式及有效期间。尚待复核的自定义项目须先由另一位有权人员发布，再加入工资方案。

编辑窗口的“规则与参数”提供：输入变量、项目与公式、来源待遇、跨模块取数公式。“主体与有效期”填写公司、体系、生效时间和调整依据。保存形成待复核版本，须另一位有权人员复核发布。已确认工资保持原版。

## 二、普通公式、变量和项目引用

输入变量可以来自个人工资档案或已核考勤报告。金额、时薪、分钟、小时、天数、比例等单位分别声明，不能把分钟直接当金额。工资项目可引用本方案输入变量及其他工资项目编码；系统检查未知变量、依赖循环、单位不符和除零。

示例：

```text
monthly
round(monthly * 0.1, 2)
prorata(monthly, present_days, work_days)
if(monthly >= 10000, 500, 200)
max0(monthly - 5000)
round(BASIC_MONTHLY * 0.05, 2)
```

示例中的变量必须先登记并提供已核值；不是内置字段的名称不会自动变成业务数据。正式算薪缺失来源时阻断，不能把未知当0。

“函数库与可引用数据”可查看函数签名、说明和示例，点击变量、项目或函数插入当前公式。“公式校验与试算”使用与服务端相同的计算引擎，输入样例数值后逐项显示结果及依赖。样例试算不生成工资；正式算薪重新读取已核数据。

## 三、函数库

| 函数 | 用途 |
|---|---|
| if | 条件取值 |
| round | 四舍五入，明确小数位；省略时沿用新版默认2位 |
| ceil / floor | 向上、向下取整 |
| abs | 绝对值 |
| sqrt | 精确有理数平方根；非精确结果会阻断，须先明确核定精度 |
| power | 整数幂，指数-16至16 |
| mod | 余数，符号随被除数 |
| min / max | 多值取小、取大 |
| greatest / least | 多值最大、最小 |
| coalesce | 首个明确非空值；不吞掉未核来源或缺失变量 |
| max0 / min0 | 以0封底、封顶 |
| prorata | 金额×实际÷应出，应出不能为0 |
| and / or / not | 布尔逻辑；也支持AND、OR、NOT写法 |

支持加减乘除、括号、比较和项目之间引用。保留“公式代码与触发器”的独立版本、代码预演与审批入口；表达式、代码扩展与实际工资确认各有状态。

## 四、跨模块数据自动影响工资

在“跨模块取数公式”增加规则，依次选择来源模块、来源项目、目标工资项目并填写公式。`source_amount`代表该人员该来源当前已核金额，可同时引用本工资方案的个人工资参数、考勤变量和普通工资计算结果。

示例：

```text
source_amount
round(source_amount * 1.1, 2)
round(source_amount + monthly * 0.1, 2)
round(source_amount * 0.5, 2)
```

- 绩效：读取当前已核准、成绩已发布且无阻断申诉的正式奖金，不会把A/B两套试算都发放。
- 培训考试：读取已核准并正式应用的奖励或技能津贴，沿用考试、资格、申诉和有效期守卫。
- 宿舍：自动读取本月已发布、同一实际雇佣、有工资扣结授权的员工费用，保留费用原始金额和结算渠道核对。
- 历史绩效：沿用既有旧新同根对照，避免同一奖金重复入薪。
- 合同、假期：通过原业务核定采用，不能借公式覆盖已核给薪；需改变金额时先办理原业务变更。

“自动取数”适用于绩效正式奖金、培训奖励、历史绩效及完整当月宿舍费用。“无来源阻断”开启时，该员工缺少所需来源或无权读取就不能继续；关闭表示没有符合条件来源时不生成该项目。此设置须随方案独立复核。

目标项目不能同时由普通公式再生成；来源的应发、扣款、福利、成本性质不能互换。宿舍费用不得超过已核授权金额。系统统一保留原来源、公式版本、输入、原金额和计算结果；来源变更后重新预演。同一奖励/费用沿原父义务确认净差，重复计算不产生第二份支付。

本轮支持统一引用已核金额及已登记的工资/考勤变量，不提供任意跨表SQL、任意未核成绩或外部接口值直接发薪。原始成绩、资格等先在绩效、培训考试模块核定并形成奖金/津贴来源。

## 五、工资表与Excel

“员工工资档案”与“批量定薪与调薪”按员工分行、工资项目分列。直接修改格子中的金额，金色标记改动并显示原值。支持Tab、Enter切换、Excel矩形金额粘贴、统一填值、按金额或比例调整。

点击上方“Excel导入”，无需预先勾选员工。下载空白CSV模板（可用Excel编辑），或上传XLSX/CSV，也可粘贴含表头的表格。按永久人员编号或雇佣编号匹配；同人多门店任职请使用雇佣编号。核对原值、新值后填入工资表，再点“保存并提交”，由另一位HR审核。空白不调整，0表示明确清零。文件含公式、外链、错误单元格、未知人员或受限项目时不能直接覆盖。

同一工资方案的新公式修订可以继续使用原有已核工资参数；新增必需参数仍须补齐。独立的另一方案不能借用已绑定其他方案的工资档案。

## 六、实测路线

1. 普通工资参数及夜班津贴公式：修改、试算、保存待审。
2. 宿舍已核费用100元，公式按50%扣结：确认扣50元，净工资4950元。
3. 同一宿舍义务改为75%：只追加25元差额，原工资保留。
4. 已核绩效1560元，公式加个人月薪1000元的10%：奖金1660元，总工资2660元。
5. 培训考试已核奖励100元，同公式加100元：奖励200元，总工资1200元。
6. 同一来源重复预演，净差为0，避免重复发放。

以上为隔离验收算例，不是客户真实工资或生产政策。两地法定政策、银行付款、工资确认和外部申报分别留状态。
